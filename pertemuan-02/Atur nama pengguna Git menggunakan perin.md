Atur nama pengguna Git menggunakan perintah: git config -- global user.name "Nama Lengkap"
Ganti "Nama Lengkap" dengan nama mahasiswa. Contoh: git config --global user.name "Aidil Fitra Antona"
Selanjutnya, atur alamat email menggunakan perintah: git config --global user.email "2611500014@mahasiswa.atmaluhur.ac.id" . Contoh: git config -- global user.email "satpam@atmaluhur.ac.id" . Gunakan alamat email
yang digunakan mahasiswa untuk identitas Git.
Setelah konfigurasi dilakukan, periksa kembali dengan menggunakan perintah: git config -- global
user.name dan git config -- global user.email .
